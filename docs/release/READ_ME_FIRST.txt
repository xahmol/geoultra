GeoUltra: what is in this download
==================================

GeoUltra is a GEOS-compatible system for the Commodore 64 with an
Ultimate 64, Ultimate 64 Elite or Commodore 64 Ultimate (firmware 3.15
or later).

geoultra64.crt, geoultra64.cfg
    The system. Copy both into one folder on the Ultimate's USB stick or
    SD card (for example /USB0/GEOULTRA/), keep both names, and run
    geoultra64.crt from the Ultimate's file browser.

GEOULTRA_MANUAL.pdf
    The user manual: installing, the desktop, disk images, Settings,
    printing, fonts, serial numbers, gush, limits, what was tested.
    Start with "Getting started".

TOOLS_MANUAL.pdf
    PC tools for GEOS disk images, geoWrite documents and geoPaint
    pictures (in the source repository's tools folder).

samples/geoultra-samples.d81
    Sample documents: a brochure, a quick start guide and a letter
    (geoWrite 2.1) and the GeoUltra logo (geoPaint). Copy it to the
    stick, mount it on a drive and open the documents in your own
    geoWrite. samples/brochure.pdf and samples/quickstart.pdf are the
    same documents as PDF.

README.pdf, LICENSE
    About the project (with how AI is used in it) and its licence
    (GPL-3.0).

You need your own GEOS applications as disk images; GeoUltra contains
no Berkeley Softworks code and ships no GEOS software. This is a beta:
back up your disk images before you start.
